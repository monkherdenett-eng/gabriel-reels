# Gabriel reels

Товлосон reel-үүд — Gabriel Forex Trading Arena & Education (Facebook) ба gabriel.wavecounter (Instagram).

- `videos/<огноо>_<id8>.mp4` — нийтлэх видео (Submagic-ийн товлосон export-оос 60 fps, H.264-оор шахсан).
- `manifest.json` — пост бүрийн огноо, цаг (Улаанбаатар), caption, видеоны URL. n8n-ийн «Gabriel — Scheduled Reels (IG + FB)» workflow үүнийг 30 минут тутам уншиж, тухайн өдрийн цаг болсон постыг нийтэлнэ. Нэг caption-тай пост аль хэдийн байвал давтахгүй.
- Эх сурвалж: Submagic-д 2026-11-26-ны байдлаар товлогдсон 90 пост (2026-11-28 … 2027-05-25, 2 хоног тутам 13:00).

Пост нэмэх, өөрчлөх: `manifest.json`-д мөр нэмж, видеог `videos/`-д хийгээд push хийнэ.
